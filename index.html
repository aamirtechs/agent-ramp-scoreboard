Agent Ramp Scoreboard

New hire ramp analytics by cohort only, so managers can coach a ramp problem in week 2 instead of discovering it in month 2.

Free100% in your browserNo sign-up

Runs 100% in your browser. Your files never leave this device.

Reporting is aggregated by cohort only. There is no individual ranking in this tool, on screen or in the download.

How it works

  • Group input by cohort and week on floor before anything is displayed, so per-agent rows are never rendered.
  • Cohorts below the minimum size are suppressed with an explicit note, not quietly merged.
  • A cohort below band on compliance QA creates a coaching task. The framing is coaching, never discipline.
  • Sample rows use synthetic agents only, named Agent 001, Agent 002 and so on.
